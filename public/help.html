Text Processing Studio

A comprehensive text processing web application. Process, compare, transform, and analyze text with an intuitive interface and powerful features.

🚀 Key Features

Text Processing Operations

  • Text Statistics - Lines, characters, unique lines with case sensitivity options
  • Sorting - Ascending, descending, or random line sorting
  • Deduplication - Remove duplicate lines with case-sensitive/insensitive options
  • Text Transformation - Uppercase, lowercase, trim whitespace
  • Line Operations - Reverse lines, remove empty lines, keep top/bottom N lines
  • Text Trimming - Remove whitespace from start, end, or both sides of lines
  • Line Filtering - Keep or remove lines based on search patterns with three search modes
  • Text Splitting/Joining - Split text by custom separators or join lines with separators
  • Prefix/Suffix - Add text to the beginning or end of each line
  • Substring Extraction - Extract specific character ranges from each line
  • Text Insertion - Insert text at specific positions within each line
  • Extract Between Delimiters - Extract text between two delimiters

Text Comparison & Analysis

  • Side-by-Side Comparison - Compare two texts in parallel panels
  • Common Lines - Extract lines that exist in both texts
  • Unique Lines - Find lines unique to left text, right text, or both
  • Visual Highlighting - Highlight common or different lines with color coding
  • Search & Highlight - Three search modes: Standard, LIKE Pattern, and Regex
  • Flexible Filtering - Keep or remove lines based on search patterns
  • Advanced Replace - Replace text with support for regex capture groups

User Experience

  • Three-Panel Interface - Left, Right, and Result panels with resizable layout
  • Output Destination Control - Choose whether commands output to active panel or result panel
  • Command Palette - Open with Cmd/Ctrl+K to search commands, reuse recent actions, and route results with Shift or Alt/Option modifiers
  • Drag & Drop - Drop text files directly into panels
  • File Operations - Import, export, copy to clipboard
  • Undo/Redo - Full history tracking for all panels (Cmd/Ctrl+Z)
  • Theme Support - Light and dark themes
  • Responsive Design - Works on desktop and mobile devices
  • Privacy-First - All processing happens in your browser, no data sent to servers

🔒 Privacy & Security

  • Client-Side Processing - All operations happen in your browser
  • No Data Transfer - No text content is sent to external servers
  • Local Storage - Settings stored locally in browser
  • File Handling - Files processed entirely in browser memory

Search Modes

The application supports three search modes for flexible text matching:

Standard Mode (Default)

Use case: Simple exact text matching

Features:

  • Exact text matching with literal string search
  • All special characters are treated literally (no escaping needed)
  • Fast and straightforward

Example:

Text: "hello world, hello universe"
Search: "hello"
Result: Matches "hello" exactly (2 matches)

LIKE Pattern Mode

Use case: Flexible pattern matching with wildcards

Wildcards:

  • % = matches any sequence of non-whitespace characters
  • _ = matches exactly one character

Examples:

Prefix Match:

Text: "hello, hello123, helloworld"
Pattern: "hello%"
Matches: "hello", "hello123", "helloworld"

Suffix Match:

Text: "myfile.txt, yourfile.txt, readme.md"
Pattern: "%.txt"
Matches: "myfile.txt", "yourfile.txt"

Single Character Wildcard:

Text: "cat, cot, cut, cart"
Pattern: "c_t"
Matches: "cat", "cot", "cut" (but not "cart")

Regex Mode

Use case: Advanced pattern matching with full regex power

Features:

  • Full JavaScript regular expression support
  • Multiline mode enabled (^ and $ match at line boundaries)
  • Supports capture groups for advanced replacements
  • Test your patterns at Regex101 (select "JavaScript" flavor)

Examples:

Line-End Anchor:

Text: "hello\nworld\nbello"
Pattern: "llo$"
Matches: Lines ending with "llo": "hello", "bello"

Character Classes:

Text: "test123, hello456"
Pattern: "[0-9]+"
Matches: "123", "456"

Capture Groups for Replacement:

Text: "John Smith, Jane Doe"
Pattern: "(\\w+) (\\w+)"
Replacement: "$2, $1"
Result: "Smith, John, Doe, Jane"

Substring Extraction

The Substring command replaces each line with a substring based on:

  • Start index: 1-based position (1 = first character)
  • Length: Optional number of characters to keep

Positive Start Index

Extract from position 3 (no length)

Input:

hello world
apple banana
test string

Command: Start=3, Length=(empty)

Output:

llo world
ple banana
st string

Extract from position 1 with length 5

Input:

hello world
apple banana
test string

Command: Start=1, Length=5

Output:

hello
apple
test

Negative Start Index

Negative indices count from the end of each line:

  • -1 = last character
  • -2 = second-to-last character

Extract last 5 characters

Input:

hello world
apple banana
test string

Command: Start=-5, Length=(empty)

Output:

world
anana
tring

Use Cases

  1. Extract file extensions: Start from last dot position
  2. Remove prefixes: Start=N where N is after the prefix
  3. Get first N characters: Start=1, Length=N
  4. Get last N characters: Start=-N
  5. Extract middle portion: Start=N, Length=M

How to Use

Basic Text Processing

1. Load Text

  • Paste text directly into the Left panel
  • Drag & drop a file into any panel
  • Import from file using the file import button

2. Select Operation

Choose from various operations in the Command Panel:

  • Text statistics and analysis
  • Sorting and deduplication
  • Case conversion and trimming
  • Line filtering and manipulation
  • Text transformation

3. View Results

  • Processed text appears in the active panel or Result panel
  • Use Shift+Click on command buttons to output to Result panel
  • Use Alt+Click or Option+Click to output to the active panel

Command Palette

Quickly reach any operation by pressing Cmd+K (macOS) or Ctrl+K (Windows/Linux) to open the command palette. Start typing to filter by command name, description, or category. Use the arrow keys or Tab/Shift+Tab to move through the results, then press Enter to run the highlighted command. The palette keeps your recently used commands at the top so repeated actions are only a few keystrokes away.

  • Shift+Enter sends the command output to the Result pane
  • Alt+Enter or Option+Enter routes the output to the opposite pane
  • Close the palette any time with Esc or by clicking the backdrop

Text Comparison

1. Load Texts

Add content to both Left (A) and Right (B) panels

2. Compare

Use comparison commands:

  • Extract Common - Lines that exist in both texts
  • Left Only - Lines unique to left text
  • Right Only - Lines unique to right text
  • Unique Lines - Combined unique lines from both

3. Highlight

Visualize differences:

  • Highlight Common - Color code matching lines
  • Highlight Different - Show non-matching lines

Keyboard Shortcuts

Undo/Redo

  • Cmd+Z (Mac) or Ctrl+Z (Windows/Linux) - Undo last change
  • Cmd+Shift+Z (Mac) or Ctrl+Y (Windows/Linux) - Redo

Output Destination

  • Shift+Click on command button - Output to Result panel
  • Alt+Click or Option+Click on command button - Output to active panel
  • Normal Click - Use default output setting

Command Palette

  • Cmd+K (Mac) or Ctrl+K (Windows/Linux) - Open or close the palette
  • Arrow Keys / Tab - Navigate between command results
  • Enter - Run selected command (combine with Shift or Alt/Option for output routing)
